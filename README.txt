المُصلّي — نسخة Web/PWA أولية قابلة للتشغيل

التشغيل:
1) ارفع المجلد على استضافة HTTPS (مثل GitHub Pages أو Netlify)، أو شغّله عبر خادم محلي.
2) افتح index.html واتصل بالإنترنت لجلب مواقيت الصلاة والقرآن.
3) من الإعدادات اختر المدينة وطريقة الحساب.
4) فعّل إشعارات المتصفح، ثم أضف التطبيق للشاشة الرئيسية.

الموجود:
- واجهة عربية RTL داكنة ذهبية.
- مواقيت الصلاة والعد التنازلي (AlAdhan API).
- تاريخ هجري، القرآن عبر AlQuran Cloud.
- أذكار مختارة، مسبحة تحفظ العدد محليًا، صفحة قبلة/موقع أولية.
- إعدادات التنبيه والصوت والاهتزاز وواجهة المكالمة.
- شاشة مكالمة تجريبية مع نطق العبارة عند الإجابة.

مهم بخصوص الخلفية والمكالمة:
- صفحات الويب لا تستطيع ضمان إشعار دقيق وقت الصلاة إذا أُغلقت/قُتلت من النظام؛ Service Worker لا يعمل كمنبه زمني دائم، وإشعارات الويب تحتاج HTTPS وإذن المستخدم ودعم المتصفح.
- شاشة المكالمة هنا تجربة داخل التطبيق فقط، ولا يمكن للويب إظهار مكالمة نظام تلقائيًا أو تجاوز قفل الهاتف. لتحقيق تنبيه خلفية موثوق ومكالمة كاملة يلزم تطبيق Android أصلي (AlarmManager/WorkManager + Notification/Full-screen intent) مع صلاحيات وإعدادات البطارية.
- مواقيت المدينة الافتراضية الرياض، غيّرها من الإعدادات.
