المُصَلِّي — مشروع Android أصلي (Kotlin)
========================================
هذا مشروع Android Studio، وليس HTML.

المزايا:
- مواقيت يومية عبر Aladhan API (طريقة أم القرى).
- تحديد موقع آخر معروف، مع إحداثيات افتراضية للرياض إذا لم يتوفر موقع.
- جدولة AlarmManager exact alarms لكل صلاة.
- إشعار عالي الأولوية مع Full-screen intent.
- واجهة مكالمة الصلاة وأزرار رد/إغلاق.
- إعدادات تفعيل المكالمات والرنين.
- إعادة فتح التطبيق عند إعادة تشغيل الهاتف (لإعادة الجدولة يدويًا عبر تحديث المواقيت).

طريقة البناء:
1. فك ZIP.
2. افتح مجلد AlMusalli في Android Studio (Open).
3. انتظر Gradle Sync.
4. Build > Build APK(s).
5. ثبّت APK على جهازك وامنح أذونات الإشعارات والموقع والمنبهات الدقيقة.
6. في Android 14+ راجع إذن إشعارات ملء الشاشة من إعدادات التطبيق إن ظهر.

تنبيه صريح:
- لا أرفق APK مبنيًا؛ هذا مصدر مشروع جاهز للبناء في Android Studio.
- يلزم اختبار على الجهاز وتطوير إضافي لإعادة جدولة المواقيت تلقائيًا بعد إعادة التشغيل،
  وتوافق قيود الشركات المصنعة/توفير البطارية. لا يمكن ضمان فتح واجهة ملء الشاشة دائمًا؛
  Android قد يعرض إشعارًا بدلها إذا رفض المستخدم الإذن أو قيّد النظام ذلك.
- راجع توثيق Android: Full-screen intents وExact alarms.
