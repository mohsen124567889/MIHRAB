# مِحراب MIHRAB — prototype v2
واجهة ويب عربية بها إعدادات فعلية تحفظ في localStorage، وإظهار/إخفاء وحدات، toggles مستقلة للتنبيهات، مواقيت محسوبة بمكتبة Adhan، عداد تسبيح وأذكار، زاوية قبلة حسابية.
## تشغيل
استضف index.html على HTTPS (GitHub Pages). يسمح المتصفح بالموقع والإشعارات عند الطلب.
## حدود صريحة
- لا تعتبر هذه النسخة تطبيقًا أصليًا أو تنبيهًا خلفيًا موثوقًا. المؤقت يعمل طالما الصفحة مفتوحة فقط؛ إغلاقها/قتلها يمنع JavaScript من التوقيت.
- لا توجد قاعدة مصحف كامل أو API أذكار شاملة مضافة في هذه النسخة؛ واجهة القرآن تعرض آيات الفاتحة فقط. لا يوجد compass sensor integration.
- لتطبيق حقيقي عند الإغلاق وشاشة تنبيه متقدمة: Android Kotlin + AlarmManager + BroadcastReceiver + إعادة جدولة بعد reboot + صلاحية exact alarms/notifications + اختبار قيود البطارية على الأجهزة.
