# المُصلّي — GitHub Pages
نسخة Web/PWA عربية RTL أولية بواجهة داكنة ذهبية.

## التشغيل
- ارفع محتويات المجلد إلى مستودع GitHub.
- Settings → Pages → Source: GitHub Actions.
- سيُنشر الموقع تلقائيًا عبر workflow في `.github/workflows/deploy.yml`.

## المميزات الموجودة
- مواقيت الصلاة عبر AlAdhan API، مع الموقع الجغرافي بإذن المستخدم.
- القرآن عبر AlQuran Cloud API.
- أذكار، مسبحة، قبلة حسابية، أدعية، تقويم هجري، متابعة ختمة، أهداف يومية.
- إعدادات طريقة الحساب، شاشة تذكير تجريبية، PWA/Service Worker.

## تنبيهات مهمة
- هذه نسخة مستقلة مستوحاة من فئة تطبيقات الصلاة وليست نسخة رسمية أو نسخًا حرفيًا من AlMosaly.
- شاشة «المكالمة» محاكاة داخل التطبيق؛ صفحات GitHub لا تستطيع إجراء مكالمة هاتفية نظامية أو تشغيل Full-screen alarm عند قفل الهاتف.
- إشعارات الصلاة الدقيقة في الخلفية تحتاج Android Native (Kotlin) مع AlarmManager/Notification channels وصلاحيات Android، أو backend Push؛ المتصفح لا يضمنها.
- يحتاج الإنترنت لجلب القرآن والمواقيت لأول مرة. الـService Worker يخزن واجهة الموقع.
