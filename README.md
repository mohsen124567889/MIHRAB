# مِحراب | MIHRAB
تطبيق ويب تقدمي (PWA) عربي لمواقيت الصلاة والقرآن والأذكار والمسبحة.

## التشغيل
- افتح `index.html` عبر استضافة HTTPS (GitHub Pages أو Netlify).
- امنح إذن الموقع للحصول على مواقيت حسب موقعك.
- فعّل الإشعارات من داخل التطبيق.
- لإضافة GitHub: أنشئ مستودعًا وارفع جميع الملفات، ثم Settings → Pages → Deploy from branch → main.

## تنبيه مهم
هذه نسخة MVP قابلة للتجربة وليست تطبيق أندرويد أصليًا. المتصفح لا يضمن إطلاق شاشة اتصال هاتفية أو تشغيل صوت تلقائي عند قفل الشاشة؛ الإشعارات والتوقيت في الخلفية تختلف حسب الجهاز والمتصفح. للتنبيه الموثوق بالخلفية وشاشة اتصال كاملة نحتاج بناء Android Native (Kotlin) مع AlarmManager/Foreground service وإذن الإشعارات، ولا يمكن ضمان 100% على كل الأجهزة.
مواقيت الصلاة عبر مكتبة Adhan CDN، وبعض وظائف المصحف/القبلة مجرد واجهات أولية وتحتاج استكمال وربط مصادر موثوقة.
