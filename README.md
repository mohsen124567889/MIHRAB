# MIHRAB v3 — polished UI
واجهة عربية فاخرة محسنة: لوحة رئيسية، cards، تنقل سفلي، إعدادات switches حقيقية محفوظة، تشغيل/إيقاف إظهار الوحدات والتنبيهات الفردية، حساب مواقيت عبر Adhan JS، عداد ذكر ومسبحة، زاوية قبلة حسابية، تاريخ هجري.
## تشغيل
استضافة `index.html` على HTTPS (GitHub Pages).
## حدود بوضوح
هذا إصدار ويب تجريبي، ليس Android أصليًا. JavaScript timer لا يعمل موثوقًا بعد إغلاق الصفحة أو قتلها، ولا توجد شاشة اتصال حقيقية. المصحف الكامل، بنك الأذكار الكامل، compass sensor، والتنبيه الخلفي native لم تكتمل. يلزم تطبيق Android/Kotlin لتلك الوظائف.
